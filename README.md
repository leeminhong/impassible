# 인파서블 (Impassible)

**2026 관광데이터 활용 공모전 · ②-2 웹·앱 구현 부문 · 지정과제 2 (오버투어리즘 분산) · 팀 MM**

> 인파(人波)를 피하는 것이 가능하다(Possible).
> 한국관광공사 관광지 집중률 예측·연관 관광지 데이터로 과밀을 예측하고, 한적한 대안 코스를 추천하는 오버투어리즘 분산 웹 서비스.

## 서비스

- 웹: https://leeminhong.github.io/impassible/
- 로그인 불필요 · 모바일/데스크톱 반응형 (900px 이상 2단 레이아웃)

## 활용 OpenAPI 4종 (한국관광공사)

1. 관광지 집중률 방문자 추이 예측 정보 — 향후 30일 집중률 (장소별 상대지수, 최번기 = 100)
2. 기초지자체 중심 관광지 정보 — 쏠림 앵커 정의(중심순위 50위 이내), 좌표
3. 관광지별 연관 관광지 정보 — 티맵 내비 동선 기반 함께 방문한 관광지 → 대안 후보
4. 국문 관광정보 서비스 (TourAPI) — 대안지 주변 카페·볼거리 위치기반 조회, 좌표 보강

API 키는 Vercel 서버리스 프록시(`impossible-tour-ai.vercel.app/api/kto`)에 은닉되며, 프록시가 응답을 6~24시간 캐시해 일일 트래픽 한도를 보호합니다.

## 판정 규칙

- 혼잡 3단계: 한산 <50 · 보통 50~74 · 붐빔 ≥75 (이곳 기준 상대지수 — 장소 간 비교 금지)
- 쏠림 앵커: 중심 관광지(관광 카테고리) ∩ 집중률 관광지(이름 정규화·별칭 연결) 중 중심순위 50위 이내
- 장소 대안: 앵커의 연관 관광지 중 관광 카테고리 · 앵커보다 25p 이상 낮음 · 이 날 한산 우선(없으면 보통을 "덜 붐비는 곳"으로) · 연관 20위 이내·같은 중분류 우선. 타 시군구 후보는 그 시군구의 집중률을 추가 로드해 판정. 혼잡 데이터가 없는 곳은 추천하지 않음
- 날짜 대안: 같은 장소 30일 중 집중률 최저일

## 서비스 지역

서울 9개 구(종로·중·용산·성동·마포·서초·강남·송파·강동) + 경주·강릉·속초·제주시
